# 住宅价格预测与结果组合

## 项目目标

在 Kaggle Learn 的住宅价格任务中预测销售价格，以平均绝对误差（MAE）评价，单位为美元。

## 工作内容

- 比较公开的价格预测结果，在超算上完成多组权重组合。
- 对候选组合进行对比，保留表现更好的三项结果组合。

## 结果

三项公开预测以 **0.60 / 0.30 / 0.10** 的权重组合，公开榜 MAE 为 **11,728.04 美元**。预测来源于公开方案，权重比较与组合由本项目完成。
