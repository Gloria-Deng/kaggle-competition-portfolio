# 乘客生存预测

## 项目目标

根据乘客特征预测生存情况，练习分类建模、类别特征处理与预测结果对比。

## 工作内容

- 建立分类模型，并修复训练集与测试集类别编码不一致的问题。
- 比较公开方案和投票组合的表现。

## 结果

自行训练版本公开榜准确率为 **0.74880**；复用 taeyangg4 的公开预测达到 **0.83014**。另有使用公开答案匹配得到的满分结果；该结果反映答案匹配，不作为模型泛化能力指标。
