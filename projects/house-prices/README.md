# 住宅价格回归

## 项目目标

根据 Ames 住宅特征预测房价，以 RMSLE 评价，越低越好。

## 工作内容

- 复现 illuminatep 的公开住宅价格方案，比较不同随机种子的模型结果。
- 对三个结果在对数空间求平均，并与其他组合方式对比。

## 结果

三种子组合的公开榜 RMSLE 为 **0.10612**；原公开方案在本人账户上的结果为 **0.10646**。
