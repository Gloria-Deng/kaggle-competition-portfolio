# 大模型生成文本来源识别

## 项目目标

根据生成文本识别其来源模型，关注测试提示与训练提示不同时的分类表现。

## 工作内容

- 复现和比较公开模型组合，处理模型、推理输出及运行环境的衔接。
- 对已有公开方案进行运行调整，整理不同版本在平台上的表现。
- 跟踪比赛评分状态：已提交且完成评分的结果，与尚在评分的候选分开记录。

## 结果

已完成评分的最佳公开榜成绩为 **0.682**（2026 年 11 月 10 日提交）。该成绩来自公开方案的复用与运行调整，原方案及依赖在公开程序中列明。
