# 质谱驱动的分子结构识别

## 项目目标

根据质谱数据对候选化学结构排序，识别复杂样品中的小分子。

## 工作内容

- 复现公开的候选生成、结构打分与排序流程，整理模型及外部资源的依赖关系。
- 对提交环境和数据输入进行适配，比较不同公开方案的运行结果。
- 将可见运行与比赛评分运行区分记录。

## 结果

公开榜成绩 **0.487**，来自复现 alexchilton 等作者公开的 Peaks to Structures 方案；2026 年 11 月 14 日 13:15（北京时间）的榜单记录为 **451 / 5,258 队**。该成绩对应公开方案复用，后续候选的评分结果以平台完成评分为准。
