# 太空船乘客状态预测

## 项目目标

根据乘客信息预测是否被传送，使用准确率评价。

## 工作内容

- 整理乘客特征和公开预测方案，比较不同模型及组合结果。
- 采用 taeyangg4 的公开预测结果，并开展其他模型的交叉验证对照。

## 结果

复用公开预测的公开榜准确率为 **0.82604**；另进行了 TabPFN 等模型的特征和验证实验。
