# 零售门店销量预测

## 项目目标

预测 Favorita 门店和商品类别的销量，评价指标为 RMSLE，越低越好。

## 工作内容

- 对多个公开预测结果进行逐行对齐，分析不同方案之间的差异。
- 将相似预测归为一组，再按组分配权重，避免同类方案数量过多而主导组合。
- 比较组内组合、中位数以及其他权重方式的比赛成绩。

## 结果

组合公开预测的版本将公开榜 RMSLE 从 **0.41288 降至 0.37699**；2026 年 11 月 14 日 17:17（北京时间）位列 **20 / 635 队**。成绩来自公开方案的组合，项目主要工作是比较、权重设计与结果验证。
