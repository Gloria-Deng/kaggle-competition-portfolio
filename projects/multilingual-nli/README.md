# 多语言自然语言推理

我比较了 DeBERTa、XLM-R 等模型判断蕴含、矛盾和中立的结果，再单独调整英文样本的模型权重。按语言组合后，公开榜准确率为 **0.94995**。公开数据里找到的标签对应关系单独记录，模型准确率以这一组合为准。
