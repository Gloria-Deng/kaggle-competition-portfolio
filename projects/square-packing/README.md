# 方中方装箱

把 N 个单位正方形放进尽量小的正方形里，不同的 N 往往适合不同布局。我逐题比较 20 份公开结果，选用其中 263 道布局，其余 737 道沿用上一份组合，再用比赛程序检查拼接后的得分。

这次组合在 2026 年 11 月 14 日提交，公开榜得分 **22.1580062504**，当天 17:17（北京时间）排 **139 / 2,054**。新选布局里，179 道来自 alexchilton，44 道来自 jazivxt，32 道来自 areebbb。
