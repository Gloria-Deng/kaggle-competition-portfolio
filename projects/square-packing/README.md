# 方中方几何装箱与方案组合

## 项目目标

为不同数量的单位正方形寻找更小的正方形容器。每个数量对应一道独立布局问题，总分越低越好。

## 工作内容

- 整理公开布局，以每道题为单位比较容器边长，组合不同来源中较优的可用方案。
- 对组合后的布局使用比赛评分程序检查，并比较预计得分与实际得分。
- 记录每个来源的采用数量，便于复核组合结果。

## 结果

2026 年 11 月 14 日提交的组合在公开榜得到 **22.1580062504**；当天 17:17（北京时间）位列 **139 / 2,054 队**。本次从 20 份公开结果中选择了 263 道布局，其余 737 道沿用已有组合。新选布局主要来自 alexchilton（179 道）、jazivxt（44 道）和 areebbb（32 道）；布局由原作者提供，本项目完成比较、组合和验证。
