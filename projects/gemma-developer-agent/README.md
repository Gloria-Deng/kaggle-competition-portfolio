# Gemma 软件开发智能体

我用 Gemma 31B 配了一个做代码维护题的智能体，给它六种开发工具和固定的调用预算。我比较了几个公开做法，调整它定位问题、修改文件和提交结果时的指令。

首个完成评分的版本公开榜得分 **0.20**，在 2026 年 11 月 14 日 17:17（北京时间）排 **447 / 5,697**。配置参考了 verracodeguacas、flexonafft、dmitriigluzdov、honghanhhh 和 boristown 的公开方案。
