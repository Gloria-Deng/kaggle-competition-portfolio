# Gemma 软件开发智能体

## 项目目标

为软件工程任务配置基于 Gemma 的开发智能体，使其在工具调用和时间限制下完成定位、编辑和提交。

## 工作内容

- 配置 31B 模型、6 种开发工具及调用预算，组织问题定位、代码编辑和提交步骤。
- 阅读比赛执行程序与公开方案，针对工具调用、文件修改及结果提交调整指令。
- 比较不同配置的公开榜结果，并记录仍在评分的版本。

## 结果

已完成评分的首版公开榜得分 **0.20**；2026 年 11 月 14 日 17:17（北京时间）位列 **447 / 5,697 队**。该版本综合了 verracodeguacas、flexonafft、dmitriigluzdov、honghanhhh、boristown 等公开方案中的思路；后续版本仍需平台给出评分。
